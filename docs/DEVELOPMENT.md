## 边界与限制

本机采集只覆盖同机 Xray；其他节点、TUIC 等独立核心不由本地 Xray 状态代表。
不自动开启 Xray 统计或访问日志，不修改或重启 3x-ui。部署要求独立 systemd
服务及最小读取权限，Web 进程不读取原数据库。详见 `deploy/LOCAL_SOURCE.md`。

GitHub Actions 已完成 v0.4.1 测试、构建和服务生命周期检查。Docker 镜像尚未实机验证。Telegram 的接收效果
需使用部署环境的实际配置验证。测试存在一条上游 TestClient 兼容弃用警告。
代理日志记录的是连接与目标，不能还原 HTTPS 内容，也不等于网页浏览次数。

代码、前端依赖及运行数据相互分离。`.venv/`、`frontend/node_modules/`、
`frontend/dist/` 与 `data/` 被 Git 忽略。真实服务器配置、登录资料与部署备份
应始终位于仓库之外。旧版本遗留的数据目录不再使用，但升级不会删除其文件。
